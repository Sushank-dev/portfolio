# 3D Assets & Tools for the Web

## Creation & Integration

### [Spline](https://spline.design/)
- **Best For:** Easy 3D creation for non-3D experts.
- **Key Features:** Browser-based editor, React component export, interactive events.
- **Why it's great:** Handles interactivity (hover/click) without complex code.

### [React Three Fiber (R3F) Examples](https://docs.pmnd.rs/react-three-fiber/getting-started/examples)
- **Best For:** Advanced, custom 3D scenes in React.
- **Key Features:** Portals, physics, atmospheric effects.
- **Why it's great:** Open-source "recipes" for high-end WebGL effects.

## Assets (Models & Textures)

### [Poly Haven](https://polyhaven.com/)
- **Best For:** High-quality realism.
- **Key Features:** CC0 (Free) 3D models, HDRI environments, textures.
- **Why it's great:** The best source for realistic lighting and materials.

### [Sketchfab](https://sketchfab.com/)
- **Best For:** Massive variety of models.
- **Key Features:** Huge marketplace, glTF downloads.
- **Why it's great:** Find almost any specific object you need. Filter by "Downloadable".
