# Portfolio Resources Skill

## Overview

This skill provides a curated list of modern, visually appealing UI libraries, 3D assets, and animation tools suitable for web development portfolios. It helps users select the right technology stack for creating high-impact visual experiences.

## Categories

- **UI Libraries**: Pre-built components and styling systems for unique layouts. See [references/ui_libraries.md](references/ui_libraries.md).
- **3D Assets & Tools**: Resources for creating or finding 3D objects and scenes. See [references/3d_assets.md](references/3d_assets.md).
- **Animations**: Libraries for adding motion and interactivity. See [references/animations.md](references/animations.md).

## Usage

When asked for portfolio recommendations or resources, this skill suggests specific tools based on the user's needs (e.g., "I need a unique hero section" -> Suggest Aceternity UI).
