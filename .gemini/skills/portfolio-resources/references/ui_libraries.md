# UI Libraries for Portfolios

## Trending & Aesthetic (React/Tailwind)

### [Aceternity UI](https://ui.aceternity.com/)
- **Best For:** High-impact "wow" factor components.
- **Key Features:** Glowing backgrounds, typewriter effects, 3D card hovers.
- **Tech Stack:** React, Tailwind CSS, Framer Motion.
- **Why it's great:** Copy-paste components that look custom-coded.

### [Magic UI](https://magicui.design/)
- **Best For:** Polished, interactive details.
- **Key Features:** Bento grids, animated lists, complex text gradients.
- **Tech Stack:** React, Tailwind CSS.
- **Why it's great:** Focuses on subtle, high-quality interactions.

### [HyperUI](https://www.hyperui.dev/)
- **Best For:** Clean, functional layout patterns.
- **Key Features:** Headers, testimonials, FAQs.
- **Tech Stack:** Tailwind CSS (HTML/React/Vue).
- **Why it's great:** Free, extensive collection of standard UI patterns.

### [UIVerse](https://uiverse.io/)
- **Best For:** Creative, community-made elements.
- **Key Features:** Unique buttons, loaders, cards.
- **Tech Stack:** Pure CSS/Tailwind.
- **Why it's great:** Wildly creative designs you won't find in standard libraries.
