# Animation Libraries for the Web

## Core Animation

### [Framer Motion](https://www.framer.com/motion/)
- **Best For:** React layout and component animations.
- **Key Features:** Layout transitions, enter/exit animations, gesture support.
- **Why it's great:** The standard for React. Declarative and powerful.

### [GSAP (GreenSock)](https://gsap.com/)
- **Best For:** Complex, timeline-based sequences.
- **Key Features:** ScrollTrigger, morphing, physics-based motion.
- **Why it's great:** Industry leader for heavy, scroll-driven storytelling sites.

## Specialized

### [LottieFiles](https://lottiefiles.com/)
- **Best For:** Vector illustrations that move.
- **Key Features:** JSON-based animation, lightweight, scalable.
- **Why it's great:** bridge between After Effects and the web.
