# Interactive Portfolio

An interactive one-page portfolio built with:

- React + TypeScript
- Tailwind CSS
- Framer Motion
- Three.js via `@react-three/fiber` and `@react-three/drei`

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Personalize quickly

- Update your profile and CTA text in `src/App.tsx`
- Replace project cards in `src/data/content.ts`
- Replace timeline entries in `src/data/content.ts`
- Change your email/social links in `src/App.tsx`
- Tune colors and UI mode styles in `src/index.css`
